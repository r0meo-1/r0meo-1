# Роман Неклюдов — поддержка ПО, CRM и тестирование

Архангельск · удалённая работа · UTC+3

Ищу работу в технической поддержке ПО, сопровождении CRM и интеграций. Также рассматриваю ручное/API-тестирование.

Есть стажировка в технической поддержке и практика в семейном турагентстве «Апрель Тур»: компьютерное оборудование, CRM, веб-формы и Telegram/VK-боты. Окончил курс «Инженер по тестированию» в Яндекс Практикуме в 2024 году.

## Проектная практика

В TurBot участвую в тестировании и сопровождении пользовательских сценариев: путь заявки до CRM, сохранение и продолжение диалога, воспроизведение ошибок и проверка изменений. В портфолио есть тестовая документация, API-проверки и SQL-проверки качества данных.

Код, автотесты и часть документации подготовлены с существенной помощью AI.
